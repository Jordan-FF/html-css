Falando sobre semântica

para um endereço podemos utilizar a tag <address> pois é a forma ideal para significado, e a navegação for no celular, pode ocorrer de termos um atalho para o maps.

Para deixar em negrito, devemos utilizar o <strong>.

Para deixar me itálico, devemos usar o <em>.

Para utilizar o 'marca texto' utilizamos o <mark>, e para colorir todos os 'mark' de uma vez, deve-se utilizar o CSS.

Para textos menores, utilizamos o <small>.

Para textos 'deletados', deve-se utilizar o <del>.

Para textos inseridos que dão ênfases para ser lido, utiliza-se o <ins>.

Para sobrescrever(para baixo) usa-se o <sub>.

Para subescrever (para cima) usa-se o <sup>.

Para demonstração de código na página, devemos utilizar o o <code>
